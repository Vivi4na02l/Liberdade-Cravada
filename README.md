# Liberdade Cravada

An interactive web experience exploring the evolution of democracy in Portugal during and after the Carnation Revolution (1974), combining historical information, data visualization and gamified interaction.

This project was developed as my **Master’s Final Project in Interactive Digital Media**.

## 🎯 Concept
Liberdade Cravada aims to communicate complex historical and political information through interactive web design.

The experience is divided into three main areas:
* Historical timeline
* Electoral data visualization
* Interactive mini-games

## 🌐 Website Structure
**Interactive Timeline**  
A chronological exploration of key historical events leading to the 1974 revolution.

**Elections Data Visualization**  
Interactive data visualizations built with D3.js, allowing users to:
* Select a specific year
* View election results through bar charts
* Compare party votes using an interactive circular chart
* Filter and select parties for comparison

**Games Section**  
Four interactive mini-games:
* Two improved versions of a previous project of mine ("Liberty Breakout") mini-games
* Two newly developed games
With two different interaction modes:
* Keyboard input
* Hand detection using **ml5.js**

## 🛠️ Tech Stack

## 🧠 What I focused on

* Data visualization using D3.js
